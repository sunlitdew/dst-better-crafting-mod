This client-sided mod aims to improve player experience when utilizing the game's crafting system

The main feature is the addition of a recursive search for sub-ingredients that might be craftable using any available crafting recipe, compared to the base game's search which is only one layer deep and only checks the basic recipe (for which the name matches the name of the ingredient).

In addition, the name of the ingredient that will be crafted, as well as the amount of products, is displayed on the crafting button. The button is given an additional potential action of having the player unequip a tool that might be used as an ingredient for crafting.
